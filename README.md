# sgssi-26-27-zekai-lin

Programas desarrollados en los laboratorios de la asignatura Sistemas de Gestión de Seguridad de Sistemas de la Información (SGSSI) 2026-2027, EHU.

Autor: Zekai Lin

## Requisitos

- Python 3 (`python3 --version`)

No hace falta instalar ninguna librería adicional.

## Cifrado simétrico (`cifrado_simetrico/`)

| Programa | Qué hace | Cómo ejecutarlo |
|---|---|---|
| `cesar.py` | Ataque de fuerza bruta contra el cifrado César | `python3 cifrado_simetrico/cesar.py` |
| `sustitucion.py` | Ataque al cifrado por sustitución simple mediante análisis de frecuencias (interactivo) | `python3 cifrado_simetrico/sustitucion.py` |
| `xor.py` | Cifrado y descifrado de flujo mediante XOR | `python3 cifrado_simetrico/xor.py` |
